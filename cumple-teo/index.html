Conectar con GitHub

Para guardar los cambios en tu repositorio, pega un token de GitHub (se hace una sola vez por dispositivo):

  1. Abre github.com/settings/personal-access-tokens/new
  2. Repository access → Only select repositories → crisacuna-portfolio
  3. Permissions → Repository → Contents: Read and write
  4. Genera el token y pégalo aquí
